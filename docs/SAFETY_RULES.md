# DDoS Attack Platform - 安全守则与使用规范

> **必须阅读并签署确认后方可部署使用**

---

## ⚠️ 核心原则

### 1. 仅限授权内网环境
- **严禁** 对未书面授权的目标发起任何攻击
- **严禁** 在生产网络、公共互联网、第三方网络中使用
- 仅允许在 **隔离的实验网段** (如 10.100.0.0/16) 内进行教学演练

### 2. 网络隔离要求
| 要求 | 说明 |
|------|------|
| 独立 VLAN | 攻击/靶机/控制网络物理或逻辑隔离 |
| 无互联网路由 | 实验网段不可访问外网，防止意外泄露 |
| 流量镜像 | 生产验证时使用镜像流量，非直接攻击 |
| 旁路部署 | 防御设备建议旁路/镜像模式，不串联核心链路 |

### 3. 权限最小化
- Controller: 普通用户，仅需 Docker 权限
- HTTP 攻击节点: 普通用户，无特权
- RAW 攻击节点: 仅需 `CAP_NET_RAW`，禁止 `--privileged` 除非必要
- 所有容器以非 root 用户运行 (UID 1000)

### 4. 熔断机制 (强制生效)
- **全局熔断**: Controller 一键停止全网攻击 (<100ms 生效)
- **自动熔断**: 超过全局限流配额自动拒绝新攻击
- **超时熔断**: 攻击自动在设定时长后停止 (最大 3600 秒)
- **心跳熔断**: 节点心跳丢失 90 秒自动标记离线

### 5. 审计与不可抵赖
- 所有指令/执行/异常全链路结构化日志 (JSONL)
- 日志含: 时间戳、操作者、节点、攻击参数、结果、成功/失败
- 日志保留 ≥ 90 天，建议接入 ELK/Splunk
- 关键操作 (熔断、场景启动) 需双人确认机制

## ✅ 部署前检查清单

### 环境准备
- [ ] 获取书面授权文件 (盖章/签名)
- [ ] 确认实验网段 CIDR，配置 `ALLOWED_TARGET_CIDRS`
- [ ] 网络隔离验证: 实验网段无法访问生产/互联网
- [ ] 证书生成: `./deploy/generate_certs.sh` (CA + Controller + 所有节点)
- [ ] 共享密钥生成: `openssl rand -hex 32` 写入 `SHARED_SECRET`

### 配置验证
- [ ] Controller `config.env` 所有项已填写
- [ ] 每个 Attacker `config.env` 匹配角色 (HTTP/RAW)
- [ ] 证书文件放置正确 (`controller/certs/`, `attacker/certs/`)
- [ ] 端口无冲突 (Controller 8443, Attacker 8080)

### 功能测试
- [ ] Controller 启动健康检查通过 (`/health`)
- [ ] 节点注册成功 (Controller `/api/v1/nodes` 可见)
- [ ] 心跳正常 (WebSocket `/ws/metrics` 收到节点心跳)
- [ ] 熔断测试: 触发 `/api/v1/emergency_stop` 所有攻击 <100ms 停止
- [ ] 白名单测试: 攻击非白名单 IP 被拒绝并审计记录

### 应急预案
- [ ] 确认物理/逻辑断网开关可达
- [ ] 制定攻击失控回滚流程 (含联系人、电话、操作步骤)
- [ ] 靶机业务有降级/熔断方案
- [ ] 监控告警配置: 攻击流量超阈值、节点离线、熔断触发

## 📋 使用流程规范

### 教学演练标准流程
```
1. 会前准备
   ├── 确认授权文件有效期
   ├── 确认实验拓扑、目标 IP、预期效果
   ├── 所有参与人员签署知情同意书
   └── 录制环境基线指标 (CPU/内存/网络/业务延迟)

2. 演练执行
   ├── Controller 启动场景 (如 cc_attack)
   ├── 实时监控: Grafana + Controller WebSocket
   ├── 观察防御系统响应 (拦截率/延迟/误封)
   ├── 如需调整: 实时修改攻击参数 (PATCH /api/v1/attacks/{id})
   └── 发现异常: 立即触发熔断 (POST /api/v1/emergency_stop)

3. 演练结束
   ├── 确认所有攻击已停止 (GET /api/v1/attacks 为空)
   ├── 导出审计日志、攻击报告、防御效果数据
   ├── 恢复环境基线
   └── 形成演练报告归档
```

### 参数调整原则
- 单次调整幅度 ≤ 2 倍
- 观察间隔 ≥ 30 秒
- 关注业务指标 (延迟 P99、错误率、吞吐) 而非仅攻击指标
- 业务指标异常 → 立即熔断

## 🔐 证书与密钥管理

| 文件 | 存放位置 | 权限 | 轮换周期 |
|------|----------|------|----------|
| CA 密钥 | 离线冷存储 | 600 | 2 年 |
| CA 证书 | 所有节点 `/certs/ca-cert.pem` | 644 | 2 年 |
| Controller 密钥 | `controller/certs/controller-key.pem` | 600 | 1 年 |
| Controller 证书 | `controller/certs/controller-cert.pem` | 644 | 1 年 |
| 节点密钥 | `attacker/certs/node-key.pem` | 600 | 1 年 |
| 节点证书 | `attacker/certs/node-cert.pem` | 644 | 1 年 |
| SHARED_SECRET | 密码管理器 / 环境变量 | - | 90 天 |

**泄露应急**: 发现私钥/密钥泄露 → 立即全网熔断 → 吊销 CA → 重新生成全套证书 → 重新部署
